# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:
To develop the Student Online Exam Registration System using Star UML tool.

# SRS (Procedure):
**STEP 1:**

Student Online Exam Registration System is required to replace the manual process of registering students, managing student details, and maintaining academic records.

**STEP 2:**

Manual processes cause difficulties in maintaining student records, verifying documents, managing course details, and handling registration.

**STEP 3:**

Students face challenges in creating accounts, submitting applications, selecting courses, uploading documents, and checking registration status.

**STEP 4:**

College administrators need an automated system to manage student details, course information, registrations, document verification, and academic records.

**STEP 5:**

The system should support student registration, login, course selection, document upload, application verification, fee payment, and report generation.

**STEP 6:**

It must provide secure access for students, administrators, and staff while protecting student information and ensuring data security.
